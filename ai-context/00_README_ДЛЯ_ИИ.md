\# Инструкция для любого ИИ, который работает с проектом WOBuy

1\. Сначала обязательно прочитай файлы в следующем порядке:  
 \- 01*SYSTEM_PROMPT.md  
 \- 02*ПРАВИЛА*БЕЗОПАСНОСТИ.md  
 \- 12*ТЕКУЩИЙ_СТАТУС.md

2\. Затем при необходимости читай остальные документы по номерам.

3\. Всегда работай только в режиме vibe-coding.  
4\. Весь код, комментарии, интерфейс и документация — только на русском человеческом языке.  
5\. Никогда не коммить секреты, ключи и токены.  
6\. После каждого значимого изменения обновляй файлы:  
 \- 12*ТЕКУЩИЙ*СТАТУС.md  
 \- changelog.md  
 \- 13*ПРОМПТЫ*ИСТОРИЯ.md

7\. Проект полностью автономный, только бесплатные тарифы, готов к переходу на платные без переписывания.
