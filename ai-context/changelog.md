# Changelog

## 2026-09-04

- Создан базовый каркас Next.js 15, Supabase Auth и V2 auth UI.
- Настроены RLS, индексы каталога и серверный поиск.
- `npm run format` сохранён как команда форматирования; отдельный workflow автоформатирования удалён, чтобы CI был единым и предсказуемым.
- Добавлена инфраструктура ingestion: `ingestion_runs`, дедупликация и защищённая Edge Function `ingest-catalog`.
- Принято решение полностью эмулировать каталог до подключения маркетплейсов.
- В Supabase загружены 12 демонстрационных товаров и 16 предложений.
- Добавлен `/product/[id]` и расширена V2-выдача поиска для проверки полного товарного сценария.
- Добавлены `/privacy` и `/terms`.
- На главной добавлены рабочие секции «Как это работает», «Тарифы», «О нас».
- Кнопка «Найти лучшее» теперь передаёт запрос в `/search`; карточка рекомендации открывает подборку.
- Auth получил единый возврат на главную, логотипы ведут на `/`, V2 login подключён к реальному Supabase Auth.
