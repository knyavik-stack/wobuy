## 2026-09-04

### Создание базового каркаса проекта

Задача: создать базовый каркас на Next.js 15 с App Router, TypeScript, Tailwind CSS, ESLint и Prettier.

Результат: каркас создан и подготовлен к дальнейшей разработке.

### Подключение и реализация Supabase Auth

Задача: безопасно подключить Supabase Auth, сделать email/password login/register, confirmation, callback, защиту dashboard, logout и восстановление пароля.

Результат: auth flow реализован через `@supabase/ssr`, middleware и cookie-based SSR.

### Перевод auth UI на V2

Задача: использовать только утверждённые V2-макеты и устранить 404 на auth-маршрутах.

Результат: auth-маршруты подключены к V2, recovery переведён на реальный Supabase flow, старые макеты удалены.

### Реальный каталог и поиск

Задача: подключить `/search` к Supabase вместо демонстрационных моков.

Результат: добавлен серверный `searchProducts()` и V2-выдача на базе `products` + `product_offers`.

### Системное устранение проблем форматирования

Задача: исключить повторяющиеся красные CI из-за Prettier.

Результат: `npm run format` сохранён как локальная/CI-команда, а отдельный workflow автоформатирования удалён. Теперь остаётся один CI-пайплайн без дублирования.

### Основа ingestion-пайплайна

Задача: подготовить безопасный слой для загрузки и дедупликации предложений маркетплейсов.

Результат: `ingestion_runs`, уникальность `marketplace + external_id`, `canonical_key` и защищённая Edge Function `ingest-catalog`.

### Переход на полную демо-эмуляцию

Задача: не ждать API маркетплейсов, а отладить весь продукт на контролируемых демонстрационных данных.

Результат: Supabase-каталог наполнен 12 демонстрационными товарами и 16 предложениями. Создан `/product/[id]`, расширена V2-выдача, добавлены `/privacy` и `/terms`.

### Исправление пользовательского пути главной и авторизации

Задача: убрать мёртвые пункты главного меню, сделать рабочей кнопку «Найти лучшее», дать пользователю понятный путь из auth обратно на главную и устранить имитацию логина.

Результат: главная навигация и поиск подключены к рабочим маршрутам; auth получил возврат на главную; V2 login использует реальный Supabase Auth; отдельный workflow автоформатирования удалён.

### Механика поиска и кабинета

Задача: довести демо-путь от поиска до пользовательского кабинета без реальных API маркетплейсов.

Результат: добавлены пользовательские таблицы и RLS для избранного, сохранённых поисков и истории; карточка товара сохраняет избранное и фиксирует просмотр; кабинет показывает рабочие разделы; поиск получил фильтры, сортировку и демо-аналитику.

### Капитальная механическая ревизия

Задача: устранить повторяющиеся CI-ошибки и убрать места, где интерфейс выглядел рабочим, но действие было заглушкой.

Результат: регистрация V2 подключена к реальному Supabase Auth; исправлена причина ESLint в карточке товара; история просмотров защищена от частого дублирования; шапка главной закреплена при прокрутке, якоря учитывают её высоту; настройки кабинета получили реальное редактирование имени; добавлены loading/error states и единый 404.
