# История промптов

## 2026-09-04

### Создание базового каркаса проекта

Задача: создать базовый каркас на Next.js 15 с App Router, TypeScript, Tailwind CSS, ESLint и Prettier.

Результат: каркас создан и подготовлен к дальнейшей разработке.

### Подключение и реализация Supabase Auth

Задача: безопасно подключить Supabase Auth, сделать email/password login/register, confirmation, callback, защиту dashboard, logout и восстановление пароля.

Результат: auth flow реализован через `@supabase/ssr`, middleware и cookie-based SSR; добавлены `/login`, `/register`, `/auth/callback`, `/dashboard`, `/forgot-password`, `/reset-password`.

### Стабилизация CI/CD

Задача: довести CI до зелёного состояния, устранить предупреждение Node.js на Vercel и убрать временную автоматизацию.

Результат: CI run #60 полностью успешен; Node.js закреплён на `22.x`; временные workflow удалены.

### Перевод auth UI на V2

Задача: использовать только утверждённые V2-макеты и устранить 404 на auth-маршрутах.

Результат: `/login`, `/register`, `/forgot-password`, `/reset-password` подключены к V2; добавлены совместимые `/auth/login`, `/auth/register`, `/auth/reset`; старые `maket/LoginPage.tsx`, `maket/RegisterPage.tsx`, `maket/ResetPasswordPage.tsx` удалены. Восстановление пароля переведено с имитации на реальный Supabase `resetPasswordForEmail` + `updateUser`.

Следующая задача: реализовать поиск и страницу результатов по `maket/SearchResults.tsx`, затем подготовить слой данных для сбора, нормализации и AI-агентов.
