Задача: создать базовый каркас на Next.js 15 с App Router, TypeScript, Tailwind CSS, ESLint и Prettier.

Результат: каркас создан и подготовлен к дальнейшей разработке.

### Подключение и реализация Supabase Auth

Задача: безопасно подключить Supabase Auth, сделать email/password login/register, confirmation, callback, защиту dashboard, logout и восстановление пароля.

Результат: auth flow реализован через `@supabase/ssr`, middleware и cookie-based SSR; добавлены `/login`, `/register`, `/auth/callback`, `/dashboard`, `/forgot-password`, `/reset-password`. Секреты не добавлялись.

Задача: автоматически проверять проект на push и pull request в `main`.

Результат: workflow выполняет install, typecheck, lint, format:check и production build. Исправлены ESLint/PostCSS и форматирование 26 файлов. Финальный CI run #28 успешен, Vercel deployment актуального коммита успешен.
