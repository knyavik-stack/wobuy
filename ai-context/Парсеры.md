Публичный внутренний API WB (без токена):
Сам сайт Wildberries обращается к открытым JSON-эндпоинтам — они доступны без авторизации: 

Один товар по артикулу (nmId):

text
GET https://card.wb.ru/cards/v2/detail?nm={артикул}&dest=-1257786
Возвращает цену, скидку, остатки по складам, рейтинг, отзывы, бренд. 

Поиск/каталог по запросу:

text
GET https://search.wb.ru/exactmatch/ru/common/v18/search?query={запрос}&page=1&sort=popular
Возвращает список товаров с ценами, рейтингами, брендами. 

Меню каталога:

text
GET https://static.wbstatic.net/data/main-menu-ru-ru.json
Отдаёт структуру всех категорий WB — нужно для обхода каталогов. 

Ограничения: каталог отдаёт максимум ~100 страниц по ~30 товаров — около 3000 позиций на запрос. Для сбора всех товаров по нише нужно перебирать категории и подкатегории. При массовом парсинге WB банит IP уже после 15–20 запросов подряд — нужны паузы или прокси. 

Готовые парсеры на Python
Минимальный рабочий пример получения карточки по артикулу:
import requests

def get_product_by_article(article: int) -> dict:
    url = "https://card.wb.ru/cards/v2/detail"
    params = {"appType": 1, "curr": "rub", "dest": -1257786, "spp": 30, "nm": article}
    headers = {"Accept": "application/json"}
    response = requests.get(url, params=params, headers=headers, timeout=10)
    response.raise_for_status()
    product = response.json()["products"][0]
    return {
        "brand": product["brand"],
        "price": product["salePriceU"] / 100,
        "rating": product.get("reviewRating"),
        "feedbacks": product.get("feedbacks"),
    }

print(get_product_by_article(12345678))


OZON:
Основной эндпоинт
text
POST https://www.ozon.ru/api/entrypoint-api.bx/page/json/v2
Или альтернативный:

text
POST https://www.ozon.ru/api/composer-api.bx/page/json/v2?url=/search/?text=ноутбук
В теле запроса передаётся params — например, URL товара или поисковый запрос. Ответ приходит в формате JSON, товары лежат в поле widgetStates (ключи вида tileGrid2-*).

Что нужно для работы
Обычный requests не сработает — Ozon закрыт Cloudflare, и без правильного TLS-отпечатка запрос уходит в капчу. Чтобы обойти это: 

Библиотека curl_cffi — имитирует TLS-отпечаток Chrome, Cloudflare пропускает запрос. 
Заголовок x-o3-app-version — берётся из DevTools браузера (F12 → Network → Headers), соответствует версии фронтенда Ozon. Меняется при каждом обновлении сайта. 
Мобильный User-Agent — часть парсеров ходит через mweb-версию (mweb_client), которая чуть менее агрессивно фильтрует ботов. 
Что можно получить
Список товаров по поисковому запросу (название, цена, ссылка, картинка, SKU)
Карточку товара по URL (характеристики, отзывы, медиа)
Обход категорий через пагинацию (nextPage или catalog.totalPages) 
Чего нельзя
Точные остатки. Ozon намеренно показывает категорийные метки: «мало» (1–3 шт.), «достаточно» (4–10 шт.), «много» (>10 шт.). Точное число — только через Seller API и только по своим товарам. 
Бесплатный доступ без ограничений. Структура ответа меняется 2–3 раза в год, Cloudflare периодически усиливает защиту, при агрессивном парсинге IP банит.
