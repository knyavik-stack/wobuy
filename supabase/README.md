# Supabase

Здесь будут SQL-миграции и инфраструктурные настройки Supabase.

## RLS

Row Level Security включается на каждой таблице с пользовательскими или иными защищаемыми данными. Политики должны ограничивать доступ через `auth.uid()` и принцип наименьших привилегий.

Пока схема базы данных WOBuy не создана, SQL-политики не добавляются искусственно: это исключает ложное ощущение защищённости и привязку Auth к неподтверждённой модели данных.

## Auth

Next.js использует cookie-based SSR через `@supabase/ssr`. Сервер и браузер используют только публичные переменные `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY`. Service Role Key и другие привилегированные секреты в приложении не используются.
