# ИСТОРИЯ ПРОМПТОВ И ИТЕРАЦИЙ

## Итерация: Настройка триггеров GitHub Actions (25.09.2026)
- **Запрос пользователя**: Actions не появились на GitHub после пуша.
- **Причина**: В файле workflow `ci.yml` ветка была жестко привязана только к `main`. Если дефолтная ветка в репозитории `master`, либо пуш был без изменений в ветке, GitHub не активировал запуск. Также отсутствовала директива ручного запуска.
- **Выполненные действия**:
  1. В `.github/workflows/ci.yml` добавлены ветки `main` и `master` для событий `push` и `pull_request`.
  2. Добавлен триггер `workflow_dispatch` — теперь в GitHub во вкладке Actions появляется кнопка "Run workflow" для мгновенного ручного запуска.
