## Итерация: Синхронизация package-lock.json для npm ci в GitHub Actions (25.09.2026)
- **Запрос пользователя**: Ошибка `npm ci` в GitHub Actions: `package.json and package-lock.json are out of sync` из-за добавления новых пакетов (`socks-proxy-agent`, `https-proxy-agent`, `undici`).
- **Выполненные действия**:
  1. Выполнена перегенерация `package-lock.json` через `npm install`.
  2. Проведено локальное контрольное тестирование `npm ci` — все 396 пакетов установились чисто за 1 прогон без ошибок.
  3. Проверена компиляция всего проекта (`compile_applet`).
