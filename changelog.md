# Changelog

## 2026-09-05

- Завершена ревизия цепочки: auth → dashboard → карточка товара → поиск → accessibility → финальная проверка CI.
- Добавлен `.prettierignore` для исключения служебных каталогов (`.next`, `node_modules`, `dist`), код приведен к стандарту Prettier (`npm run format:check` — зелёный).
- Проверена карточка товара `/product/[id]`: корректность работы избранного, сортировка предложений по минимальной цене, безопасные ссылки на маркетплейсы (`target="_blank" rel="noreferrer"`), fallback на демо-каталог при отсутствии ключей Supabase.
- Проверен личный кабинет `/dashboard`: серверные действия удаления поиска и истории, переключение избранного, валидация имени профиля и формы смены пароля.
- Проверена страница выдачи `/search`: компактные раскрывающиеся фильтры, сохранение поисковых запросов, переключение видов сетка/список.
- Проверена доступность (a11y): все интерактивные кнопки снабжены `aria-label`, поля форм имеют связку с `<label>`, обеспечен фокус и контрастность на тёмном фоне.
- Успешно пройден полный локальный CI-пайплайн: `npm run typecheck`, `npm run lint`, `npm run format:check`, `NODE_ENV=production next build`.
- `/search` получил современную компактную раскрывающуюся панель фильтров: категории и сортировка не занимают постоянное место на экране.
- Добавлено переключение отображения каталога: desktop-сетка 3 карточки в ряд или горизонтальный список.
- Выбор вида каталога хранится в URL и не ломает фильтры/сортировку.
- Убран устаревший `maket/SearchResults.tsx`; V2 остаётся единственным макетом выдачи.
- V2 выдачи очищена от старого `createClient` и неиспользуемых импортов; предупреждение raw image явно подавлено для demo-изображений.
- Убрана лишняя верхняя панель общего auth-layout.
- Убрано лишнее верхнее пространство над логотипом auth-экрана.
- Добавлен favicon `src/app/icon.svg`.
- Обновлены metadata: заголовок сайта, шаблон title и русское описание для поисковиков/вкладки браузера.
- Hero уплотнён сверху, уменьшена демонстрационная карточка и закрыто overflow фоновых glow-элементов.
- Якорная навигация главной переведена на программный scroll с фиксированным offset, чтобы секции `#features`, `#pricing`, `#about` физически не прятались под fixed header.
- Добавлено компактное мобильное меню главной навигации с корректным закрытием после выбора секции.
- На уровне документа закреплён тёмный фон и `overflow-x-hidden`.
- Последний проверенный CI run `33916390080` успешен для предыдущего состояния: TypeScript, ESLint, форматирование и production build.

## 2026-09-04

- Создан базовый каркас Next.js 15 с App Router.
- Подключены TypeScript, Tailwind CSS, ESLint и Prettier.
- Реализован Supabase Auth: login, register, email confirmation, callback, logout, recovery и reset password.
- Настроен GitHub Actions CI: typecheck, lint, format:check и production build.
- Закреплён Node.js `22.x`.
- Landing-дизайн интегрирован в приложение, навигация и поиск работают на демо-каталоге.
- Схема каталога `products` + `product_offers`, RLS и индексы настроены.
- Добавлен ingestion-контур и защищённая Edge Function `ingest-catalog` для будущих источников.
- Принято решение полностью эмулировать каталог до подключения API маркетплейсов.
- Каталог наполнен 12 демонстрационными товарами и 16 предложениями.
- Добавлены `/product/[id]`, `/privacy`, `/terms`.
- Пользовательские таблицы избранного, сохранённых поисков и истории просмотров получили RLS.
- Кабинет получил рабочие разделы и редактирование имени профиля.
- Поиск получил категории, сортировку и демо-аналитику.
- Регистрация V2 переведена с имитации на реальный Supabase Auth.
- Добавлены loading/error states и единый экран 404.
