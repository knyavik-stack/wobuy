# Changelog

## 2026-09-04

- Создан базовый каркас на Next.js 15 с App Router.
- Подключены TypeScript, Tailwind CSS, ESLint и Prettier.
- Реализован Supabase Auth: login, register, email confirmation, callback, logout, recovery и reset password.
- Настроен GitHub Actions CI: typecheck, lint, format:check и production build.
- Исправлены конфигурации ESLint/PostCSS и форматирование проекта.
- `package.json` закреплён на Node.js `22.x` для стабильного Vercel build.
- Введено системное форматирование через `npm run format`; отдельный workflow автоформатирования удалён, чтобы не плодить второй CI-процесс.
- `/forgot-password` и `/reset-password` переведены на единый утверждённый V2-дизайн и реальный Supabase recovery flow.
- Старые auth-макеты первой версии удалены, добавлены совместимые auth redirect-маршруты.
- Landing-дизайн интегрирован в приложение.
- Проверена схема каталога `products` + `product_offers`, RLS и индексы.
- Добавлен ingestion-контур: `ingestion_runs`, дедупликация предложений и товаров, защищённая Edge Function `ingest-catalog`.
- Принято решение использовать демонстрационные данные до подключения API маркетплейсов.
- Каталог наполнен 12 демонстрационными товарами и 16 предложениями.
- Поиск переведён на демонстрационный каталог без изменения будущего пользовательского сценария.
- Добавлена страница `/product/[id]` с предложениями и внешними ссылками.
- Добавлены `/privacy` и `/terms`.
- Исправлена главная навигация: «Как это работает», «Тарифы», «О нас» теперь являются реальными секциями.
- Кнопка «Найти лучшее» на главной теперь запускает реальный поиск по демо-каталогу, а «Посмотреть подборку» открывает выдачу.
- Добавлена ссылка на главную в auth-layout и кликабельные логотипы в ключевых экранах.
- V2 login очищен от имитации `setTimeout`/`console.log` и подключён к реальному Supabase Auth.
