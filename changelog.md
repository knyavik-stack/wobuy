# Changelog

## 2026-09-04

- Создан базовый каркас на Next.js 15 с App Router.
- Подключены TypeScript, Tailwind CSS, ESLint и Prettier.
- Реализован Supabase Auth: login, register, email confirmation, callback, logout, recovery и reset password.
- Настроен GitHub Actions CI: typecheck, lint, format:check и production build.
- Закреплён Node.js `22.x`.
- Введено системное форматирование через `npm run format`; отдельный workflow автоформатирования удалён, чтобы не плодить второй CI-процесс.
- Landing-дизайн интегрирован в приложение, навигация и поиск работают на демо-каталоге.
- Проверена схема каталога `products` + `product_offers`, RLS и индексы.
- Добавлен ingestion-контур и защищённая Edge Function `ingest-catalog` для будущих реальных источников.
- Принято решение полностью эмулировать каталог до подключения API маркетплейсов.
- Каталог наполнен 12 демонстрационными товарами и 16 предложениями.
- Добавлена страница `/product/[id]` с предложениями и внешними ссылками.
- Добавлены `/privacy` и `/terms`.
- Исправлена вертикальная обрезка главной страницы: шапка теперь закреплена при прокрутке, якорные секции учитывают высоту шапки.
- Добавлены пользовательские таблицы избранного, сохранённых поисков и истории просмотров с RLS.
- Карточка товара теперь сохраняет товар в избранное и фиксирует просмотр без дублей чаще одного раза в 30 минут.
- Кабинет получил рабочие разделы избранного, сохранённых поисков, истории и редактирования имени профиля через Supabase Auth.
- Поиск получил категории, сортировку по цене/рейтингу и демо-аналитику результата.
- Регистрация V2 переведена с имитации на реальный Supabase Auth с сохранением имени пользователя.
- Добавлены loading/error states для поиска, карточки товара и кабинета, а также единый экран 404.
