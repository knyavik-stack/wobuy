# WOBuy

**Домен:** wobuy.ru

Базовый каркас проекта WOBuy на Next.js 15 с App Router и TypeScript.

## Стек

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- ESLint
- Prettier

## Структура

- `src/app/` — App Router и страницы
- `src/components/` — переиспользуемые компоненты
- `src/lib/` — общие утилиты и серверная логика
- `public/` — статические ресурсы
- `ai-context/` — контекст, требования и история проекта

## Команды

```bash
npm run dev
npm run build
npm run lint
npm run typecheck
npm run format:check
```

Секреты, ключи и токены в репозитории не хранятся.
